# 도시·주거공간 정책 연구 아카이브

도시재생·주거복지·공간·GIS 분야의 정책 연구 자료를 모아 보고, 기고를 받아 구글 스프레드시트에 아카이빙하는 단일 페이지 웹 서비스입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 웹페이지 전체 (HTML·CSS·JS 단일 파일) |
| `Code.gs` | 구글 앱스 스크립트 백엔드 (기고 저장 `doPost`, 목록 조회 `doGet`) |

## 기능

- 카테고리 탭(전체/도시재생/주거복지/공간·GIS) 필터링
- 제목·본문 실시간 검색 및 검색어 강조
- 기고 폼 유효성 검사, 전송 중 로딩 상태, 완료 알림 팝업
- 낙관적 UI 업데이트: 제출 즉시 목록 맨 위에 카드 추가
- PC 2열 / 모바일 1열 반응형

## 구글 시트 연결

1. 구글 스프레드시트에서 **[확장 프로그램] → [Apps Script]**를 열고 `Code.gs` 내용을 붙여넣어 저장합니다.
2. **[배포] → [새 배포]** → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. 발급된 `https://script.google.com/macros/s/.../exec` 주소를 `index.html`의 `const GAS_URL = "";`에 넣습니다.

`GAS_URL`이 비어 있으면 데모 모드로 동작하며, 제출한 기고는 화면에만 추가됩니다.
